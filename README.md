# MATTYAS — maquette du site officiel

Prototype autonome : ouvrez `index.html` dans Chrome pour le tester.

## Publication sur GitHub Pages
1. Créez un dépôt GitHub public, par exemple `mattyas-site`.
2. Téléversez `index.html` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Attendez la publication : GitHub affichera l'adresse du site dans la section Pages.

## À personnaliser avant publication
- Remplacer les liens de démonstration par les vrais liens Mattyas.
- Pour jouer le vrai morceau `23h53`, ajouter un fichier audio (par ex. `23h53.mp3`) et remplacer le faux lecteur par un lecteur HTML `<audio controls src="23h53.mp3"></audio>`.
- Le bouton de langue bascule le texte entre français et anglais.
- Le lecteur actuel est une animation de démonstration et ne produit pas de son.
